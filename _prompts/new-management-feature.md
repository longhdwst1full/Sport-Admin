# Implement an Admin management feature

Đọc `AGENTS.md`, skill Admin feature/API integration và feature spec. Tham khảo pattern list/form/sidebar/header của `admin-client` và composition/foundation/Storybook của `dragonx-employer-web`; chỉ áp dụng pattern tương thích source hiện tại. Dùng generated SDK, mapper riêng, React Hook Form/Yup, permission/lifecycle server-backed và đủ UI states. Thêm hoặc cập nhật Storybook, rồi chạy lint, test, generate API khi contract đổi, build và build-storybook.
