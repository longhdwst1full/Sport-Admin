# Admin feature specifications

Mỗi màn quản trị có một thư mục feature spec. Bắt đầu từ `../_templates/feature-spec.template.yml`; mô tả route/menu, permission, generated OpenAPI operations, bảng/form/drawer, validation, optimistic version và đầy đủ loading/empty/error/disabled/success.

Tham khảo cấu trúc và UX vận hành của `admin-client` và `dragonx-employer-web`, nhưng map lại vào Ant Design/Tailwind/foundation hiện tại; không copy domain chứng khoán hoặc API wrapper cũ.
